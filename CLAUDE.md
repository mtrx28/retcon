# RETCON

Retractable memory for multi-agent AI on FalkorDB (Graph Hacks, Tracks 02 + 01). Beliefs carry their justifications as graph edges; `distrust(source, window)` retracts exactly what depended on it (JTMS retract-then-re-derive), blocks pending actions and lists executed ones for recall.

Two-person team, each working with their own Claude. Either of you must be able to pick up the other's work cold.

2. Read `docs/CONTRACT.md`: the frozen seam between lanes. Do not change it unilaterally.

## Design rules (do not violate)

- **FalkorDB is the only store.** No Postgres, no separate vector DB. Every write, retrieval, cascade, gate and metric is a FalkorDB query.
- **Never delete memory.** Nodes go `OUT`, stay for audit and replay; `reinstate` reverses a retraction exactly.
- **Deterministic core.** LLMs extract and phrase; graph rules decide IN/OUT. Same inputs, same state.
- **Justification semantics:** a justification is an AND of premises; a node is IN iff some justification has all premises IN. Re-derivation is Doyle-style well-founded, so circular support cannot keep a lie alive.
- **Automatic premise capture:** agents never declare parents; middleware records everything retrieved into context before a write.
- **One graph per tenant:** `tenant_<id>`.
- **All data synthetic**, generated by our seeded script. No real names, IBANs or scraping. No code copied from Veritas / MemLineage / MemTX.
- **Verify Cypher against the live engine**, not from Neo4j memory. Working syntax goes in `docs/SPIKE.md`.

## Commands

No `make` on Windows, so tasks run through `tasks.py` (use the venv python).

```bash
py -3.13 -m venv .venv && .venv/Scripts/python -m pip install -e ".[dev]"   # once (Linux/Mac: .venv/bin/python)
python tasks.py up                # FalkorDB via docker compose (Browser UI on :3000)
python tasks.py fixture           # load data/fixtures/ap_tiny.json into tenant_northwind
python tasks.py test              # pytest suite
python tasks.py accept A4         # tests marked `a4` (add the pytest marker to each task's tests)
python tasks.py spike             # re-run live-engine syntax probes
```

Verified FalkorDB syntax and gotchas (no `EXISTS {}`, single-type `maxFlow`, vector score is a distance): `docs/SPIKE.md`.
